ThePosterDB

Required. ThePosterDB sits behind Cloudflare, so requests need a browser session. Open theposterdb.com while logged in, copy the full Cookie request header from your browser's network tab (it must include cf_clearance) and paste it here.
Must match the browser the cookie was copied from, or Cloudflare rejects it.

Mediux

Sent as a bearer token to the Mediux API. Leave empty to disable Mediux. Mediux looks items up by TMDB ID, so items need a TMDB ID to return results.

General

Pause between paged requests when scraping.
